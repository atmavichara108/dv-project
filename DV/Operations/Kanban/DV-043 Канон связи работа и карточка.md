## Цель
Работы отдела разработки шли в dv-hub через ветки и PR, а карточки живут отдельно: доска показывала пустое место при живой работе.

## Definition of Done
- [x] Правило записано: работа стартовала — карточка сразу in_progress; закрыта — сразу done
- [ ] Источник праводы назван: поле status в карточке
- [x] Найдены пропущенные работы и заведены как карточки
- [x] Порядок повторяем без напоминания
