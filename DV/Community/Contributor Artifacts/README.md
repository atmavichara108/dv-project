# Contributor Artifacts

Эта зона хранит **внешние артефакты контрибьюторов**, которые приняты для
сохранения и разбора, но ещё не являются каноном проекта.

Правила зоны:

- не канон-зона: сюда не переносится автоматически в `docs/` или `context`;
- не удаление: принятый вклад не теряется, пока нет явного вердикта;
- провенанс обязателен: автор, дата получения и дата фиксации;
- правки не редактируют смыслы автора без отдельного вердикта;
- переход в канон возможен только через решение ЦУ/владельца.

- `Илья-transliteration.py` — Contributor Artifact, транслитерация от Ильи.
